# Code Video Studio — «ChatGPT 5.5: следующий уровень ИИ»

Видео-презентация, собранная кодом: 9 сцен, ≈2:30, синтезированная музыка и эффекты. Без внешних сервисов, библиотек и сервера.

> Подтверждённых характеристик ChatGPT 5.5 в проекте нет. Видео говорит об общих тенденциях ИИ; предположения в тексте названы предположениями.

## Функции
- Автоматические сцены с плавными переходами, кинетической типографикой, Canvas-эффектами и субтитрами.
- Музыка и эффекты на Web Audio API без внешних аудиофайлов.
- Плеер: пауза, перезапуск, предыдущая/следующая сцена, шкала прогресса, время и полноэкранный режим.
- Опциональный голос диктора через SpeechSynthesis браузера.
- Запись в WebM через Canvas + MediaRecorder, если браузер поддерживает эту функцию.
- Адаптивный холст 16:9, поддержка prefers-reduced-motion.
- Клавиши: Пробел, ←/→, F, M, H.

## Файлы
- `index.html` — страница видеопрезентации.
- `styles.css` — оформление.
- `script.js` — сцены, анимации, звук и управление.

## Запуск локально
Откройте `index.html` в браузере или запустите `python3 -m http.server` и перейдите на http://localhost:8000.

## Публикация на GitHub Pages
1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Source: Deploy from a branch.
3. Выберите ветку `main` и папку `/(root)), затем нажмите Save.
4. После публикации сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Ограничения
- **Звук:** браузеры запрещают автоматическое воспроизведение звука без взаимодействия — нажмите «Начать просмотр со звуком».
- **Запись:** идёт в реальном времени (≈2:30), вкладку нельзя сворачивать. Нужен браузер с MediaRecorder и WebM. Голос диктора в запись не попадает, субтитры попадают. Это запись веб-презентации, а не готовый MP4.
